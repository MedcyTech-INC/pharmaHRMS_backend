# Pharma HRMS API Backend

This is the Python FastAPI backend for the Pharma HRMS application.

## Development Setup

1. Create a virtual environment: `python -m venv venv`
2. Activate the virtual environment: `.\venv\Scripts\activate` (Windows)
3. Install dependencies: `pip install -r requirements.txt`
4. Copy `.env.example` to `.env` and fill in the values.
5. Run the development server: `fastapi dev app/main.py`
